Cloud calling keeps registration in the provider cloud and reaches the PSTN through a carrier plan, an operator connection, or a customer SBC. Cisco documents Local Gateway (often CUBE) for Webex Calling. Microsoft documents three Teams Phone PSTN models: Calling Plans, Direct Routing, and Operator Connect. Zoom Phone, RingCentral, 8x8, Dialpad, and Google Voice are other cloud voice services. Media port ranges are omitted because the vendor pages were not re-fetched on 2026-10-03.

      Failure tree

      Direct Routing trunk stays down

      Checks. TLS certificate, FQDN, and SIP OPTIONS toward Microsoft. Do not invent the FQDN.

      Likely cause. The name on the certificate does not match the trunk, or 5061 is blocked.

      Fix. Match the name Microsoft provisioned. Media ranges come from the current Microsoft Learn page.

      Inbound calls fail, outbound works

      Checks. Which numbers are assigned to the trunk or Local Gateway.

      Likely cause. The cloud still points the DID at the old route.

      Fix. Move the number in the provider admin, then test one DID.

      Local Gateway registers and calls return 404

      Checks. Dial-peer or route on the gateway, and the called-number format the cloud sends.

      Likely cause. The cloud sends E.164 and the gateway expects a different digit string.

      Fix. Normalize on the gateway. Keep a sample INVITE.
