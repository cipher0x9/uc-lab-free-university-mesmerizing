Communications platform as a service lets an application ask the platform to place or receive calls. Twilio, Vonage, and Bandwidth publish programmable voice and SIP trunking. A webhook is an HTTPS callback to your application when a call event happens. This page has no API keys, no sample credentials, and no request signatures.

    Failure tree

    The platform calls A and never calls B

    Checks. Did A actually answer, and did the application return the next instruction?

    Likely cause. The webhook did not answer, so the platform has no instruction for leg B.

    Fix. Fix the application response. Do not put a real auth token in a lab note.

    Calls connect and the webhook never fires

    Checks. Can the platform reach the application's HTTPS endpoint?

    Likely cause. The callback URL is private or the certificate fails.

    Fix. Use an address the platform can reach. Keep tokens out of the atlas.

    One-way audio on a trunk call

    Checks. SDP from the platform to your SIP side.

    Likely cause. The same c= problem as any other SIP trunk.

    Fix. Treat it as an SBC media problem. See the SBC page.
