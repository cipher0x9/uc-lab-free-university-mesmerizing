Cisco Unified Communications Manager is a cluster: a publisher holds the database, subscribers run call processing, TFTP serves phone files, and CTI serves desk applications. Unity Connection is voicemail. IM and Presence is the Cisco presence service. Expressway is the edge. CME is call processing on IOS for a small site. Avaya Aura Communication Manager, Mitel, and NEC are other PBX families. Asterisk and FreeSWITCH are open-source call platforms. Kamailio is a SIP proxy, not a PBX.

    Failure tree

    Phone cycles and never registers

    Checks. TFTP file, then SIP or SCCP toward the node in that file.

    Likely cause. The phone got a file from the wrong cluster, or signaling to CUCM is blocked.

    Fix. Confirm the TFTP server, then the signaling port for the protocol the phone actually runs.

    Desktop app cannot control the phone

    Checks. CTI TCP 2748 from the application to CTI Manager.

    Likely cause. The app is pointed at a node that is not running CTI Manager, or the user is not allowed.

    Fix. Move the CTI connection to a node that runs the service.

    Calls work on the LAN and fail after a WAN move

    Checks. RTP range 16384–32767 UDP, not just SIP 5060.

    Likely cause. Signaling is open and the media range is not.

    Fix. Permit the Cisco phone RTP range both ways.
