Speech can be forked from a live call to a recognizer (ASR) and a synthesizer (TTS) can play prompts back. The same fork can feed a transcript to an agent desktop (agent assist). None of this requires a published accuracy number, and this page prints none. Vendor feature names are omitted unless a vendor document was opened; none were re-fetched on 2026-10-03.

    Failure tree

    The agent hears audio and the transcript is empty

    Checks. Is the fork established, and is the speech service receiving RTP?

    Likely cause. Signaling to the desktop is up and the media fork is not.

    Fix. Fix the fork before you blame the recognizer.

    Prompts play and barge-in never works

    Checks. Is caller RTP reaching the recognizer during the prompt?

    Likely cause. TTS is playing and caller media is not mixed back to ASR.

    Fix. Send caller audio to the recognizer while the prompt plays, if the design calls for barge-in.

    Someone asks for a percent accurate

    Checks. This atlas does not print accuracy, latency SLAs, or MOS.

    Likely cause. Those numbers are benchmarks. They are out of scope.

    Fix. Read the vendor's own evaluation report. Do not invent one.
