IMS (3GPP TS 23.228) places P-CSCF, I-CSCF, and S-CSCF in the signaling path and keeps the subscriber profile in the HSS. Diameter (RFC 6733) is the AAA protocol on TCP or SCTP port 3868. VoLTE is the GSMA IR.92 profile of IMS voice over LTE. VoNR is profiled by GSMA NG.114, IMS Profile for Voice, Video and Messaging over 5GS. VoLTE remains IR.92. EPS fallback (3GPP TS 23.502 clause 4.13.6.1) is a setup-time move from 5GS to EPS: the NG-RAN may reject the IMS-voice QoS flow and hand the UE over, or redirect it, to E-UTRAN/EPC, where the voice bearer is set up. SRVCC (3GPP TS 23.216) moves an already active IMS voice call to the CS domain (UTRAN/GERAN). Message-by-message ladders are not drawn.

    Failure tree

    UE never registers

    Checks. Is there a default bearer, and did the UE learn a P-CSCF?

    Likely cause. LTE attach succeeded but IMS PDN or P-CSCF discovery failed.

    Fix. Check the IMS APN and P-CSCF discovery before reading SIP response codes.

    401 then a second 401

    Checks. Algorithm and synchronization on the second REGISTER.

    Likely cause. Authentication response does not match the HSS vector.

    Fix. The fault is subscriber data or time sync, not the RTP path.

    Registered, but no inbound calls

    Checks. Is the S-CSCF still holding a contact and a service route?

    Likely cause. Registration expired, or the terminating path has no reachable contact.

    Fix. Look at the registration lifetime before opening a media ticket.

    Setup versus mid-call

    EPS fallback · setup

    3GPP TS 23.502 clause 4.13.6.1. At VoNR call setup the NG-RAN may reject the IMS-voice QoS flow and move the UE by handover or redirection to E-UTRAN/EPC. The voice bearer is then set up on EPS. This is a setup-time fallback from 5GS to EPS.

    SRVCC · mid-call

    3GPP TS 23.216, Single Radio Voice Call Continuity, Stage 2. It moves an already active IMS voice call to the CS domain (UTRAN/GERAN). The call is up before the move.
