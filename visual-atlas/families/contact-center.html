A contact center answers, plays treatment, queues, and delivers the call to an agent. ACD chooses the agent. IVR collects digits or speech. CTI updates the desktop. WFO records and evaluates. Cisco UCCX, UCCE, and Packaged CCE are on-prem families. Webex Contact Center, Genesys Cloud, NICE CXone, Five9, Amazon Connect, and Talkdesk are cloud families.     Failure tree

    Callers sit in queue while agents look idle

    Checks. Agent state, skill, and whether the endpoint is registered.

    Likely cause. The agent is not in the ready state the ACD requires, or the skill does not include this queue.

    Fix. Compare one agent's state with the queue's skill rule before you add trunks.

    IVR answers, transfer to agent is silent

    Checks. Is media re-invited when the agent is connected?

    Likely cause. The platform connected signaling and left RTP on the IVR port.

    Fix. Capture both legs. The second SDP answer should name the agent or the anchor.

    Desktop does not pop

    Checks. CTI session from the desktop to the platform.

    Likely cause. The call is delivered and the CTI association is down.

    Fix. Restore CTI. The voice path can be healthy while the screen pop is not.
