Kari's Law (Public Law 115-127) requires multi-line telephone systems to allow a caller to dial 911 without a prefix and to notify a central place on site when a 911 call is made. RAY BAUM'S Act section 506 requires a dispatchable location. PIDF-LO (RFC 4119, updated by RFC 5139 and RFC 5491) is the presence document for location. RFC 6442 carries a location reference or value in SIP. ELIN is a Cisco term for an emergency location identification number. 47 CFR Part 9 holds the FCC 911 rules; paragraph text was not re-fetched from ecfr.gov in this run, so no subsection is quoted.

    Failure tree

    911 asks for a prefix

    Checks. Dial plan on the phone and the PBX.

    Likely cause. A trunk access code is required before 911. That fails Kari's Law.

    Fix. Accept 911 as dialed. Keep a notification to the site.

    Call connects and the location is the wrong building

    Checks. Which ELIN or PIDF-LO was attached to this phone's network location.

    Likely cause. The phone moved and the location record did not.

    Fix. Tie location to the place the phone is, and test after every move.

    Notification never reaches the front desk

    Checks. The notify target, separate from the PSAP leg.

    Likely cause. The PSAP call works and the on-site notify target is empty or unreachable.

    Fix. Fix the notify target. It is a different leg from the emergency call.
