A session border controller hides topology, interworks mismatched SIP, anchors media, and is the place you apply trunk policy. Cisco CUBE is the IOS XE SBC and is Cisco's documented Local Gateway for Webex Calling. Expressway-C and Expressway-E are the Cisco edge for Mobile and Remote Access and for business-to-business SIP. Ribbon, AudioCodes, and Oracle sell SBC product families; feature cells that need a current manual are marked not stated because those manuals were not re-fetched on 2026-10-03. On Expressway X15.0 the first traversal server zone uses SIP TCP 7001 and H.323 UDP 6001. Default traversal media is UDP 36000–59999, set on Expressway-C. Large Expressway-E reserves UDP 36000–36011 for multiplexed media. Small and Medium systems use demux UDP 2776/2777 or the first pair 36000/36001.

        Failure tree

        One-way audio right after cutover

        Checks. Compare SDP c= and m= on both sides of the SBC. Look for a SIP ALG on the firewall.

        Likely cause. The address or port in SDP is not the address that receives RTP.

        Fix. Disable the ALG. Make the SBC rewrite SDP to the address the far end can reach.

        Carrier sends 488

        Checks. Codec list and packetization in the offer.

        Likely cause. No common codec, or a required ptime the carrier rejects.

        Fix. Offer a codec the carrier documented, usually including G.711.

        MRA phone registers, then calls fail

        Checks. Registration 200 OK is not the same as a completed traversal media path.

        Likely cause. Signaling works and the traversal media ports do not.

        Fix. On X15.0 open UDP 36000–59999. Large Expressway-E also uses UDP 36000–36011. Small/Medium demux is UDP 2776/2777 or 36000/36001.
