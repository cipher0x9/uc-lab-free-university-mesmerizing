A session border controller hides topology, interworks mismatched SIP, anchors media, and is the place you apply trunk policy. Cisco CUBE is the IOS XE SBC and is Cisco's documented Local Gateway for Webex Calling. Expressway-C and Expressway-E are the Cisco edge for Mobile and Remote Access and for business-to-business SIP. Ribbon, AudioCodes, and Oracle sell SBC product families; feature cells that need a current manual are marked not stated because those manuals were not re-fetched on 2026-10-03. Expressway numeric traversal and media ranges are omitted until the Expressway IP Port Usage guide for the release is checked.

        Failure tree

        One-way audio right after cutover

        Checks. Compare SDP c= and m= on both sides of the SBC. Look for a SIP ALG on the firewall.

        Likely cause. The address or port in SDP is not the address that receives RTP.

        Fix. Disable the ALG. Make the SBC rewrite SDP to the address the far end can reach.

        Carrier sends 488

        Checks. Codec list and packetization in the offer.

        Likely cause. No common codec, or a required ptime the carrier rejects.

        Fix. Offer a codec the carrier documented, usually including G.711.

        MRA phone registers, then calls fail

        Checks. Registration 200 OK is not the same as a completed traversal media path.

        Likely cause. Signaling works and media ports do not. This page does not guess the media range.

        Fix. Open the media range in the Expressway IP Port Usage guide for that software version.
