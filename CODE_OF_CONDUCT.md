# Code of Conduct

## Our pledge

**UC Lab Free University** is a free educational project by **CYPHER0X9**. We pledge to make participation in this community a harassment-free experience for everyone, regardless of age, body size, visible or invisible disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, caste, color, religion, or sexual identity and orientation.

## Our standards

**Do**
- Be kind, patient, and precise
- Assume good intent; ask clarifying questions
- Share proof (LICC / RTMA) not vibes alone
- Protect privacy: never post secrets, customer data, or private dial plans
- Credit sources; pin official vendor docs for production decisions

**Do not**
- Harass, troll, or gatekeep learners
- Share production credentials, PII, or proprietary customer topology
- Demand free consulting that requires private access
- Weaponize this material for fraud, spam, or illegal intercept

## Scope

This Code applies in project spaces (GitHub issues, PRs, discussions) and when representing the project publicly.

## Enforcement

Report concerns by opening a **private security advisory** if available, or by contacting the maintainer via the GitHub profile for [@cipher0x9](https://github.com/cipher0x9). Maintainers may remove content or block accounts that violate this Code.
