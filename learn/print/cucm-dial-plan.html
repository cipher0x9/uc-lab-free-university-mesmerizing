CUCM dial-plan cheat sheet

Objects

  • Partition: where a pattern lives.
  • Calling search space: ordered partitions a caller may see.
  • Line CSS then device CSS.
  • Route pattern selects a list, trunk, or block.
  • Route list: ordered route groups.
  • Route group: gateways or trunks.
  • Translation: change digits and analyze again.
  • Transformation: change digits on egress only.

Match rules

  • More specific pattern wins.
  • Partition order breaks a tie. Line CSS is first.
  • X is one digit. The dot is the PreDot boundary, not a wildcard.
  • ! waits on the interdigit timer unless the pattern is urgent.
  • 911 must be reachable with no prefix, from every class of service.

Lab pattern

9.55501XX discards 9 and can route 555-0100 through RL-PSTN to a gateway at 192.0.2.40. A called-party transformation may prefix +1. It does not choose the gateway. Local route group lets one pattern egress the device pool's gateway.

Second lookup

A translation pattern uses its own CSS unless Use Originator's Calling Search Space is set. An empty CSS on that second lookup sees only the null partition.
